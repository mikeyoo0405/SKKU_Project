## 4. R1 오류 진단 · R2 제한적 경계 보정 구현 요약 (2026-11-22)

- **R1 (`tools/local_emotion.py`, `app/emotion.py`)**: 기존 `error`/`reason` 계약을 유지하면서 허용된 `diagnostic.stage`·`code` 및 비정상 종료 코드를 기록(원문 예외·stderr·임의 진단 필드·민감 문자열 미저장, 기존 진단 없는 실행기 호환 유지).
- **R2 (`app/candidates.py` 선정 v3, `tools/run_batch.py`, `tools/reproduce_boundaries.py`)**:
  - VAD 발화 내부 경계를 탐지해 가까운 VAD 경계까지 `0.5초` 이내이면 `0.08초` 여백으로 확장하되, 인접 ASR 발화·별도 VAD 발화·원본 범위·최대 길이(`MAX_CLIP_S`) 침범을 차단(코드 리뷰 보완: 비겹침 인접 ASR·`MAX_CLIP_S` 경계에서는 0.08초 여백만 클램프하고, 소수점 ms 원본 길이에서 `end_ms`가 `duration`을 초과 반올림하지 않도록 보완).
  - 긴 연속 발화·침범 위험은 `speech_continues_before`/`speech_continues_after`, 보정 후보는 `boundary_adjusted_check_transcript` 플래그를 남기고, 미해결 경계 위험이 없는 후보를 우선(최대 3개 유지).
  - 원래 ASR 시작·끝·ID(`source_asr_clip_id`)와 보정 밀리초(`boundary_adjustment_ms`)를 기록하고, 선정 버전 갱신 전에 이전 `state.json`을 `selection-history/{sha256}.json`에 보존. 기존 미디어·manifest·추론 이력·사람 확정 라벨 보존.
- **2단계 보완(선택 구간 자동 정지, 완료 기록)**: `static/app.js`, `static/index.html`, `static/review.mjs`, `test_review_ui.mjs`에서 선택 구간 끝점 정지·재재생·원본 이어듣기 종료를 구현했고, Ubuntu 실제 후보 사용자 청취로 끝점 자동 정지 확인 완료.

## 5. R0–R4 기능·회귀 완료 기준 참조표

자연스러운 발화 경계와 감정 정답은 사람이 평가하고, 파일·상태·분모·오류 계약은 코드로 판정합니다. LLM을 감정 정답 판정자로 사용하지 않습니다.

- **C-DIAG (실패 원인 구분)**: 잘못된 입력, 체크포인트 로딩 오류, 추론 예외, 잘못된 출력, 모델 미설치, 타임아웃의 단계·코드 식별, 다음 후보 진행·수동 검수 유지, 진단 기록 민감 문자열 미노출.
- **C-BOUND (경계·무음 개선 및 결정적 제약)**: 모든 후보가 원본 범위·최소/최대 길이 제약·유일 ID를 만족하고 음성을 삭제·이어붙이지 않음. 재현된 잘림 사례의 해소 또는 경고+수동 조정 경로 제공, 정상 대사에 새 잘림/화자 혼합 금지, 경고 추가만으로 품질 개선 집계 금지, 동일 원본에서 경계 수정률·활성 조정 시간 감소 확인.
- **C-EVAL (입력·정답 독립성 및 분모 정확성)**: 개발·최종 표본 원본 영상·화자 분리, 최종 표본 감정당 ≥ 25건·총 ≥ 100건·교차 라벨링 ≥ 10건, 독립 정답(제안 비노출), 고정 지문/버전. 전체 기준 정확도(정답/N)·커버리지(유효/N)·보류율(보류/N)과 실패율·누락률 분리 보고, 보류·실패·누락을 FN으로 반영한 전체 기준 Macro-F1·재현율과 유효 예측 분모 지표 병기. 원시 logit을 모델 간 공통 신뢰도로 간주하지 않음.
- **C-PILOT (사람 시간 절감)**: 동일 URL·장비·설정에서 수정 전후 작업 묶음·순서를 교차 측정해 채택 클립당 활성 사람 시간 감소 확인.
- **G1–G3 (공통 회귀 기준)**:
  - G1: 동일 입력 재실행·추론 실패·선정 버전 변경 후 사람 확정 라벨·`annotation.json`·변경 이력 보존
  - G2: 경계 수정 새 ID·`superseded` 연결, 철회·격리, 저장 실패 복구, 부분 파일 처리, 오래된 제안·독립 검수 제안 숨김
  - G3: 선택 끝점 정지·재재생·반복·원본 이어듣기 종료, 중복 URL·후보 방지, 단건 실패 후 계속 진행
